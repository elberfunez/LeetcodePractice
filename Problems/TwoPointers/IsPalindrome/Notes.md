# Notes - Valid Palindrome

## Pattern / Approach
Two Pointers
## Data Structure(s) Used

## Thought Process
My thought process here is to break down mathematically what a palindrome is.
Let's take this example:

`racecar`

If you think about it.
1) Initialize a left pointer at the first r (first index)
2) Initialize a right pointer at the last r (last index)

As you move each pointer inward, each letter should match eachother. If they dont, you dont have a valid palindrome.
