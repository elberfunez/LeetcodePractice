# Reverse Linked List

**Difficulty:** Easy  
**Topic:** Linked List

---

## Description

Given the beginning of a singly linked list `head`, reverse the list, and return the new beginning of the list.

---

## Examples

### Example 1:

```
Input: head = [0,1,2,3]

Output: [3,2,1,0]

Explanation: The linked list is reversed from 0→1→2→3 to 3→2→1→0.
```

### Example 2:

```
Input: head = []

Output: []

Explanation: An empty list remains empty.
```

---

## Constraints

- `0 <= The length of the list <= 1000`
- `-1000 <= Node.val <= 1000`
